# Icon mô-đun Siêu cải tiến

55 icon cắt tự động từ ảnh chụp màn hình 超级改造: lưới thẻ trong game đều đặn 180×196px,
script lấy phần tranh bên trong mỗi ô (bỏ biển tên phía trên), kích thước ~132×120px.

Tên file **trùng `id`** của mô-đun trong `src/data/upgrades.json` (ví dụ `loi-bao-kich.png`),
hoặc đặt tên khác rồi khai báo field `image`.

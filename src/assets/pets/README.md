# Ảnh thú cưng

37 ảnh ở đây được cắt tự động từ ảnh chụp màn hình đồ giám (宠物图鉴) trong game:
lấy phần tranh bên trong mỗi thẻ, bỏ biển tên phía trên nhưng giữ lại bãi cỏ và huy hiệu S/EX
ở chân thẻ. Kích thước ~214×158px.

Thêm pet mới: bỏ file `.png` vào đây, đặt tên trùng trường `image` trong `src/data/pets.json`
(ví dụ `chu-tuoc.png`). Trang Thú cưng tự nhận, không cần sửa code.
Pet nào chưa có ảnh sẽ hiện ô tròn với chữ Hán đầu tên thay cho hình.

# Ảnh vũ khí

Ảnh ở đây cắt từ ảnh chụp bảng Vũ khí (武器) trong game — lấy phần tranh vũ khí ở giữa khung,
bỏ biển tên phía trên và các nút UI hai bên.

Thêm vũ khí mới: bỏ file `.png` vào đây, đặt tên trùng trường `image` trong
`src/data/weapons.json` (ví dụ `tra-sui-bot-gau-truc.png`). Trang Vũ khí tự nhận,
không cần sửa code. Vũ khí chưa có ảnh sẽ hiện ô dấu `?` thay cho hình.

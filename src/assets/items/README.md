# Icon vật phẩm cửa hàng

14 icon ở đây cắt tự động từ ảnh chụp Cửa hàng Ma Pháp (魔法商店): dò khung viền của ô icon
trong từng thẻ hàng rồi cắt đúng ô đó, kích thước ~90×90px.

Tên file **trùng với `id`** của vật phẩm trong `src/data/shop.json` (ví dụ `hat-toi-chuong.png`).
Muốn dùng tên file khác thì thêm field `image` cho vật phẩm đó. Vật phẩm chưa có icon vẫn hiện
bình thường, chỉ là không có hình.

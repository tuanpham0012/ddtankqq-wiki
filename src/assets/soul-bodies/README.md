# Ảnh hồn thể

Ảnh ở đây là phần chân dung (avatar) cắt từ ảnh chụp bảng Hồn thể (魂体) trong Thần Điện —
lấy đúng khung tranh vuông ở góc trên bên trái bảng, bỏ tên và viền.

Thêm hồn thể mới: bỏ file `.png` vào đây, đặt tên trùng trường `image` trong
`src/data/soul-bodies.json` (ví dụ `minh-uyen-quan-chua.png`). Trang Hồn thể tự nhận,
không cần sửa code. Hồn thể chưa có ảnh sẽ hiện ô dấu `?` thay cho hình.

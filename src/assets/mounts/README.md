# Ảnh thú cưỡi

Ảnh ở đây cắt từ ảnh chụp bảng Thú cưỡi (坐骑) trong game — lấy phần tranh con thú
trên bệ đá, bỏ khung UI hai bên.

Thêm thú cưỡi mới: bỏ file `.png` vào đây, đặt tên trùng trường `image` trong
`src/data/mounts.json` (ví dụ `pho-hien-linh-tuong.png`). Trang Thú cưỡi tự nhận,
không cần sửa code. Thú cưỡi chưa có ảnh sẽ hiện ô dấu `?` thay cho hình.
